# click-zero-phishing-awareness-
Click-zero phishing awareness guide that educates users about phishing attacks, how to identify warning signs and ways encourage secure  online practices  
Click Zero- Phishing awareness
Slogan: Zero Trust, Zero Victims 
Project overview
Click Zero is a cybersecurity awareness guide that educates people about phishing attacks and promote secure online activities. The guide provides information about the common phishing techniques used by criminals and ways to protect personal information.
Project Objectives
•	Provide education to users about phishing attacks
•	Promote safe internet use
•	Encourage the use of strong and unique passwords
•	Helps users identify suspicious and fraudulent emails and messages
Security recommendations
•	Do not share passwords or verification codes
•	Verify links and messages before responding
•	Enable multi-factor authentication
•	Report any suspicious emails and messages
Target Audience
Internet users, students and employees who want to advance their understanding on cybersecurity awareness.
